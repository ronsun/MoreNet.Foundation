public static class DataRecordExtensions
Remarks

Each data type has its own dedicated method instead of using a generic approach. A generic method would be 15-40% slower due to runtime type checking, boxing/unboxing overhead, and reduced JIT optimization. See benchmark: tools\MoreNet.Foundation.Benchmark\Extensions\DataRecordExtensionsBenchmark.cs
